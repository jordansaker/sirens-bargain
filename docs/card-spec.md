# Pearl & Tide — Card Design Spec
*A mermaid-themed set-collection card game (Monopoly Deal–style engine, fully original theme)*

This spec keeps the exact card counts, values, and rent tables of a proven set-collection card game, so the balance is intact. Everything here is original naming and art direction — no trademarked names, logos, or assets. Hand this file to Claude Code as the blueprint when you build.

**Total: 106 playable cards.**
Breakdown: 28 Realm (property) cards · 11 Wild Realm cards · 20 Pearl (money) cards · 13 Tribute (rent) cards · 34 Action cards.

---

## Core Goal
Be the first to complete **3 full ocean realms** (property sets) laid out in front of you.

---

Play for effect, or bank any of them for their Pearl value instead.

## Turn Structure
1. **Draw 2 cards** at the start of your turn (draw 5 if your hand is empty).
2. **Play up to 3 cards**: bank Pearls, lay down realms, or play actions.
3. **Discard** down to 7 cards in hand if over the limit.
4. Win the instant you have **3 completed realms** in front of you.

## Payment Rule
When you owe Pearls, pay from your bank and/or laid-down realm cards. If you can't cover it, you pay what you have — no change is given. Nobody owes from an empty bank if they have nothing.

## Notes for building with Claude Code
- **State model:** each player has `{ hand[], bank[], realms: { realmName: [cards] } }`. Deck is a shuffled array; discard pile is an array. Turn state tracks `cardsPlayedThisTurn`.
- **Cards as data:** define every card as a JSON object (`id`, `type`, `name`, `realm?`, `value`, `rent?`, `actionEffect?`). The whole 106-card deck is just an array you generate from the tables above — ask Claude Code to build this deck file first.
- **Build order that works well:** (1) deck + data model, (2) turn loop + banking, (3) laying realms + win check, (4) Tributes/payment **— build High Tide, Coral Cottage, and Pearl Palace here, since these are rent *modifiers* that only work as part of the rent system, not standalone actions**, (5) the independent action cards one at a time (Kraken's Grasp, Slippery Eel, Trade Winds, Toll of the Tides, Mermaid's Feast, Siren's Refusal, Ride the Current), (6) a simple AI opponent (greedy: complete sets, charge rent when able, use Siren's Refusal defensively), (7) UI.
- **Why the split matters:** High Tide has no effect on its own — it multiplies a Tribute charged the same turn and uses an extra card-play. Coral Cottage / Pearl Palace attach to an already-completed realm to raise its rent. All three depend on the rent system existing first, so they can't be built or tested in isolation.
- **Engine:** Godot (free, exports to Android + web, no royalties). Start single-player vs AI so there's zero server cost.
- **Art:** original mermaid/ocean art only. Free commercial-use asset sources or your own drawings; avoid anything ripped from existing games.
